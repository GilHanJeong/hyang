# 한길쌤’s 창작마당

교육·게임·취미 프로젝트를 위한 정적 웹사이트입니다. 빌드 과정 없이 HTML/CSS/JavaScript로 실행됩니다.

## 로컬 실행

`python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173 에 접속합니다.

## 화면 구성

- 메인: 도트 나무 타이틀, 소개, 나무패널 메뉴 세 개.
- 분야별 씬: 상단 고정 나무 탭, 홈 아이콘, 투명 공사 현장 이미지로 표시한 빈 구역 6개. 콘텐츠 문구는 없습니다.
- 교육: 현대 한국 학교 정원 산책로의 탑뷰 도트 맵. 구역 사이 간격은 동일하며 별도로 추가한 보행로는 없습니다.
- 게임·취미: 배경 디자인 전 단계로 흰 바탕 유지.
- PC 3열, 태블릿 2열, 모바일 1열. 해시 URL로 새로고침·뒤로가기 지원.

## 파일

`index.html` 화면 골격 / `app.js` 씬 이동·슬롯 생성 / `styles.css` 레이아웃.
`assets/tab-*.png` 글자 없는 나무패널이며 이름은 HTML 텍스트로 표시합니다.
`assets/school-garden.png` 교육 배경 원본. CSS repeat-y로 원본을 같은 방향으로 반복하며 상하반전하지 않습니다.

## 에셋 제작

내장 이미지 생성 도구로 제작한 시안입니다. 교정 프롬프트: 현대 한국 학교 교정, 2D 탑뷰 RPG 도트맵, 잔디와 녹지가 있는 학교 산책로, 가장자리 나무·벤치·화단·학교 일부, 텍스트 없음, 세로 스크롤에 맞춘 연결형 지형.

## 배포

기존 GitHub 자동 배포 연결을 사용합니다. 배포 루트는 저장소 최상위이며 별도 빌드 명령은 없습니다. 앱 실행이나 설치 파일 다운로드 기능은 아직 연결하지 않았습니다.

`assets/under-construction.png`: 내장 이미지 생성 도구로 제작. 프롬프트: 도트 건물 기초·벽돌·목재, 교차 로프 두 줄, 공사 중 팻말, 주변 투명. 빈 구역 이미지에는 지연 로딩을 적용합니다.
