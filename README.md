# 한길쌤’s 창작마당

교육·게임·취미 프로젝트를 위한 정적 웹사이트입니다. 빌드 과정 없이 HTML/CSS/JavaScript로 실행됩니다.

## 로컬 실행

`python -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173 에 접속합니다.

## 화면 구성

- 메인: 도트 나무 타이틀, 소개, 나무패널 메뉴 세 개.
- 분야별 씬: 배경 위에 떠 있는 원본 비율의 나무 탭과 메인 간판, 화면에 표시하지 않는 콘텐츠 배치 영역 6개. 콘텐츠 문구는 없습니다.
- 교육: 현대 한국 학교 정원 산책로의 탑뷰 도트 맵. 구역 사이 간격은 동일하며 별도로 추가한 보행로는 없습니다.
- 게임: 따뜻한 중세 판타지 마을 배경을 정방향으로 세로 반복합니다.
- 취미: 대장간·선술집·악기가 있는 공방 마을을 정방향으로 세로 반복합니다.
- PC 3열, 태블릿 2열, 모바일 1열. 해시 URL로 새로고침·뒤로가기 지원.

## 파일

`index.html` 화면 골격 / `app.js` 씬 이동·슬롯 생성 / `styles.css` 레이아웃.
`assets/tab-*.png` 글자 없는 나무패널이며 이름은 HTML 텍스트로 표시합니다.
`assets/school-garden.png` 교육 배경 원본. CSS repeat-y로 원본을 같은 방향으로 반복하며 상하반전하지 않습니다.

## 에셋 제작

내장 이미지 생성 도구로 제작한 시안입니다. 교정 프롬프트: 현대 한국 학교 교정, 2D 탑뷰 RPG 도트맵, 잔디와 녹지가 있는 학교 산책로, 가장자리 나무·벤치·화단·학교 일부, 텍스트 없음, 세로 스크롤에 맞춘 연결형 지형.

## 배포

기존 GitHub 자동 배포 연결을 사용합니다. 배포 루트는 저장소 최상위이며 별도 빌드 명령은 없습니다. 앱 실행이나 설치 파일 다운로드 기능은 아직 연결하지 않았습니다.

`assets/under-construction-v2.png`: 내장 이미지 생성 도구로 제작. 프롬프트: 도트 건물 기초·벽돌·목재, 교차 로프 두 줄, 공사 중 팻말, 주변 투명. 빈 구역 이미지에는 지연 로딩을 적용합니다.

메뉴 패널의 배경 크기는 contain으로 원본 비율을 유지합니다. 메인 간판은 `assets/tab-home.png`이며, 공사 스프라이트 2차 시안은 큰 픽셀 덩어리·제한된 색상·굵은 교차 로프·공사 중 표지로 생성했습니다. 모바일 메뉴는 2×2 배치입니다.

간판 2차 시안: 교육 원본을 이미지 편집 기준으로 사용해 메인·게임·취미의 목재 색·규격·테두리를 맞추고 양 끝 장식만 바꿨습니다. 내장 이미지 생성 도구 사용. 원본은 `assets/tab-education.png`, 변형은 `assets/tab-home-v2.png`, `assets/tab-games-v2.png`, `assets/tab-hobbies-v2.png`입니다. 비선택 탭의 어둡게 표시 효과는 유지합니다.

공사 중 이미지는 사용자 요청으로 화면에서 제거했으며 기존 에셋 파일만 보존합니다. `assets/fantasy-village.png`는 내장 이미지 생성 도구로 제작했습니다. 프롬프트: 따뜻한 중세 판타지 마을, 탑뷰 도트맵, 양옆 목조집·꽃·등불, 중앙 잔디, 같은 방향으로 세로 반복, 텍스트 없음.

`assets/artisan-village-v3.png`: 내장 이미지 생성 도구 제작. 프롬프트: 따뜻한 중세 공방 마을의 탑뷰 도트맵, 모루·강철·화덕 불꽃, 술통·검·류트·북, 중앙 이끼 낀 돌바닥, 텍스트 없이 세로 반복.


최신 게임 배경은 assets/fantasy-village-v3.png (밝은 낮), 취미 배경은 assets/artisan-village-v3.png 입니다. 위아래는 지면으로 연결하고 건물은 좌우 가장자리에서만 잘립니다. 실제 화면에서 세로 반복 경계를 확인했습니다. 최종 생성 프롬프트는 ASSET-PROMPTS.md에 기록합니다.
