# 한길쌤’s 창작마당

교육·게임·취미 프로젝트를 소개하는 정적 웹사이트입니다. 별도의 빌드 없이 HTML/CSS/JavaScript로 실행됩니다.

## 로컬 확인

프로젝트 폴더에서 `python -m http.server 4173 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:4173`에 접속합니다. 단순 확인은 `index.html`을 직접 열어도 됩니다.

## 파일 구성

- `index.html`: 타이틀, 소개, 탭, 하단 안내
- `styles.css`: PC 3열·태블릿 2열·모바일 1열, 분야별 색상, 상단 고정 탭
- `app.js`: 분야별 콘텐츠와 마우스·키보드 탭 동작
- `assets/title-wood-panel.png`: 사용자가 선택한 도트 나무 간판 타이틀

현재는 프레임 단계입니다. 메인은 타이틀·소개·분야 선택 메뉴만 표시합니다. 메뉴를 누르면 메인이 사라지고 분야별 씬으로 전환합니다. `#education`, `#games`, `#hobbies`로 직접 접속할 수 있고 뒤로가기와 새로고침을 지원합니다. 분야 화면의 메뉴는 상단에 고정됩니다. 교육 첫 카드에 언어 분석기를 소개하며 다운로드 URL은 연결 전입니다. 나머지는 준비 중 카드입니다.

## 배포

정적 사이트 호스팅의 배포 루트를 저장소 최상위로 지정하고 별도의 빌드 명령은 사용하지 않습니다. 기존 GitHub 자동 배포 연결을 사용합니다. 파이썬 분석 서버는 포함되지 않습니다.

콘텐츠 수정 후 로컬에서 세 탭 전환, 스크롤 시 탭 고정, 모바일 레이아웃, 키보드 좌우/Home/End 탐색을 확인하고 커밋·푸시합니다.
